# عالم الحروف العربية 🎈

لعبة تفاعلية ممتعة لتعليم الأطفال الحروف العربية بالصوت والصور.

## المميزات

- 🔤 جميع الحروف العربية الـ 28 مع كلمات وصور توضيحية
- 🔊 نطق الحروف والكلمات بالصوت
- 📱 تعمل على الموبايل والكمبيوتر
- ✅ تتبع تقدم الطفل في تعلم الحروف
- 🏆 شهادة تشجيعية عند إتمام جميع الحروف
- 🎉 مؤثرات بصرية احتفالية
- 👆 دعم السحب (Swipe) للتنقل بين الحروف

## التشغيل

افتح الرابط مباشرة من المتصفح — لا تحتاج تثبيت أي شيء.
